# Tiltroom

Core domain language for Tiltroom, a standalone Apple Watch tilt puzzle game.

## Language

**Tiltroom**:
The standalone Apple Watch tilt puzzle game developed in this repository.
_Avoid_: Tiltroom Collection, 倾斜游戏合集

**重力快门 (Gravity Shutter)**:
The core two-step interaction mechanic: tilting the wrist to aim gravity, then triggering a shutter action to release sliding movement.
_Avoid_: 实时重力, 连续倾倒

**Watch-only**:
A standalone watchOS app with no iOS companion app, where installation, gameplay, and progress persistence live entirely on Apple Watch.
_Avoid_: 伴侣端, iPhone 同步版
